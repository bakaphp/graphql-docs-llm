# OBJECT: ScribeQuotePaginator

A paginated list of ScribeQuote items.

## Estructura

| Campo         | Tipo              | Descripción                                     |
| :------------ | :---------------- | :---------------------------------------------- |
| paginatorInfo | `PaginatorInfo!`  | Pagination information about the list of items. |
| data          | `[ScribeQuote!]!` | A list of ScribeQuote items.                    |
