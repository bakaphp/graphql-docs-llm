# INPUT_OBJECT: ProductDiscoveryInput

## Estructura

| Campo      | Tipo      | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :--------- | :-------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| query      | `String!` | The shopper's request in their own words, in any language.                                                                                                                                                                                                                                                                                                                                                                                     |
| request_id | `String`  | Client-generated id for THIS SEARCH — one per search, not one per page or session. Echoed back, and sent again with any click or purchase so the outcome can be attributed to it. Re-sending it for the same search is safe (a cached result carries it); re-using it for a DIFFERENT search is a bug and the later search will not be recorded. REQUIRED for app-key callers; optional for a logged-in user, who gets a server-generated one. |
| company_id | `ID`      | Whose catalog to search. Optional for a logged-in user — defaults to their current company, and may only name a company they belong to. REQUIRED for app-key callers, which have no user to infer it from.                                                                                                                                                                                                                                     |
| session_id | `String`  | Anonymous browsing id, carried so a visitor's searches can be tied to their account if they sign up.                                                                                                                                                                                                                                                                                                                                           |
| limit      | `Int`     |                                                                                                                                                                                                                                                                                                                                                                                                                                                |
