# OBJECT: ScribePaymentPaginator

A paginated list of ScribePayment items.

## Estructura

| Campo         | Tipo                | Descripción                                     |
| :------------ | :------------------ | :---------------------------------------------- |
| paginatorInfo | `PaginatorInfo!`    | Pagination information about the list of items. |
| data          | `[ScribePayment!]!` | A list of ScribePayment items.                  |
